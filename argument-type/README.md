# Argument Types and Quantities

## Labelling
- `all_arguments_with_labels.csv` - all labelled arguments. Columns are: scenario id, party, arguments/noarguments, argument id, advocate model, argument, number of arguments, first argument type (1=TEXT, 2=PURPOSE, 3=SYSTEMIC, 4=PRECEDENT), last argument type, main argument type.
- `Instructions for Research Assistants.pdf` - instructions given to annotators.
- `Argument Types - Gold.csv` - gold standard type/quantity annotations by human judges.
- `ArgType_PrePrompt.txt` - prompt given to LLM to solicit argument types and quantities.
- `ArgType_Claude_Api.ipynb` - code to prompt LLM for argument types and quantities.


## Analysis
- `argument_counts_by_judge.csv` - win rates for higher numbers of arguments and p values (contained in Table 11 of the paper) - generated by `argument_types_counts_wins.py`)
- `argument_number_report.txt` - regression coefficients and p values for success predicted by argument count (contained in Table 11 of the paper). Generated from `data_for_argument_number.csv` (data for production of regression results for success predicted by argument count. Columns are judge model, number of arguments, success (1) or failure (0))
- `argument_types_diversity.csv` - data file for diversity (incl. p value) contained in Table 11 of the paper (generated by `argument_types_diversity.py`)

- `multi_regression_results.txt` - logit regression results. Generated by `process_multi_regression_arg_type.py` from `data_for_multi_regression.csv` (Table 12 of the paper).
